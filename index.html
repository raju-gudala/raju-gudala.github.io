Hands-On Projects

Hands-on projects demonstrating end-to-end hardware design, from schematic through bench validation.

KiCad STM32F427 6-Layer PCB ArduPilot

UAV Flight Controller — Ti-Circle v1

Designed a custom flight controller from scratch supporting ArduPilot firmware, routed on a 6-layer PCB with 250+ components centered around the STM32F427. Integrated a dedicated I/O co-processor and multi-rail power supply for flight-critical peripherals.

🧬 6-Layer PCB 🔲 250+ Components 📡 SPI/I2C/UART

📄 📊
EasyEDA LTspice PSpice High-Voltage

Tethered Drone Power System

Engineered end-to-end power delivery for a tethered drone platform: an AC-DC base station converting 230V AC to 360V DC @ 8A, and an isolated air-unit converter stepping that down to 24V DC @ 100A. Added real-time telemetry and automatic failover arbitration.

⚡ 2.4kW 🔋 360V DC Link 🔁 Auto Failover
🔋
📄 📊
KiCad LTspice LT8645SHV-2

5V Power Module for UAV Avionics

Designed a high-efficiency, wide-input 5V DC-DC power module supporting 3S–12S LiPo input using the LT8645SHV-2 synchronous buck converter, with reverse-polarity protection, UVLO, soft-start, and a low-EMI, low-ripple PCB layout.

🔋 3S–12S LiPo 📉 Low-EMI Layout 🛡️ UVLO + Soft-Start
🔄
📄 📊
KiCad LTspice LM2596S-ADJ

Adjustable DC-DC Step-Down Converter

Designed a wide-input adjustable buck converter using the LM2596S-ADJ, accepting 5–40V input and delivering an adjustable 3.3–15V output via a feedback potentiometer, rated for up to 3A continuous load.

🔌 5–40V In 🎚️ 3.3–15V Out ⚡ 3A
